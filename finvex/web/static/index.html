Состав платформы

Включение модуля открывает связанные разделы и маршруты API, выключение закрывает их. Защитный слой при выключении отклоняет заявки.

Песочница — отдельный слой для проверки любого агента на живых данных. Её вердикты не попадают в журнал, заявки никуда не уходят, правила и данные рабочие.

Правила выполняет код шлюза. Агент не может ни изменить их, ни обойти.

У каждого агента свой ключ и свой набор данных. Токен брокера остаётся только у шлюза.
