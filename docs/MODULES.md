# Модули Finvex

Четыре модуля с независимым включением. Состояние: `data/gateway/modules.json` (по умолчанию всё включено).

| Модуль | Требует | Что закрывается в интерфейсе | Что закрывается в API |
|---|---|---|---|
| data (адаптеры) | - | блок источников в «Настройках» | `/api/adapters*` |
| analytics | - | правила «Новостной фон» и «Прогноз Kronos» | `/api/analytics`; правила аналитики пропускаются |
| guard (защитный слой) | data | «Вердикты», «Правила», «Агенты», контекст и проверка намерения в боковой панели | `/gateway/v1/*` (503), `/api/verdicts|rules|agents|intent|context|report|export.csv` (409) |
| hub (хаб и чат) | guard | «Чат», «Песочница» | `/api/chat`, `/api/sandbox/*` (409) |

Интерфейс: разделы с выключенным модулем отмечены замком; открытие показывает страницу с причиной и кнопкой
«Включить модуль». Блоки внутри страниц заменяются пояснением. Скрытие в интерфейсе - удобство; доступ закрывает сервер.

API: `GET /api/modules`, `PATCH /api/modules {"id","enabled"}` (интерфейс, токен страницы);
`GET /gateway/v1/modules` (ключ агента) - доступные сейчас модули и маршруты.

Ограничения: модульность одного процесса, не отдельные сервисы; раздельная установка и биллинг не реализованы.
Выключенный защитный слой скрывает и историю вердиктов в интерфейсе (она остаётся на диске).
