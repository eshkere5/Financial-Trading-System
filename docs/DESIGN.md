# Дизайн интерфейса

Интерфейс рабочий (режим «операция»): плотный, тёмный, без декоративных элементов. Данные и решения важнее оформления.

## Принципы
- Иерархия: вердикты и причины первыми, настройки отдельно. Сводка вместо сетки карточек.
- Решение никогда не передаётся одним цветом: отличаются заливка, обводка и текст («Разрешено», «Доработать», «Отклонено»).
- Один акцент `--data` (синий) только для данных: график, активный переключатель, свежая строка.
- Один авторский момент движения: подсветка новой строки и выезд панели деталей; при `prefers-reduced-motion` анимации отключаются.

## Токены
- Шкала отступов 4, 8, 12, 16, 24, 32 px; шкала шрифта 12, 13, 14, 16, 20, 28 px.
- Шрифт Onest (OFL), подключён локально из `finvex/web/static/fonts`, внешних запросов нет.
- Цвета и радиусы заданы переменными в начале `app.css`.

## Доступность
- Ссылка «К содержимому», разметка по областям, `aria-current` в навигации, `aria-live` для сводки и чата.
- Детали вердикта и ключ агента открываются в `<dialog>`: фокус удерживается внутри, Esc закрывает, фокус возвращается.
- Строки таблицы открываются с клавиатуры (Enter, пробел). Цели нажатия не меньше 44 px на сенсорных экранах.
- Текст не ниже контраста 4.5:1; график имеет текстовое описание и подсказку по наведению.

## Адаптация
- От 1180 px панель актива становится выезжающей, от 720 px навигация переходит вниз экрана.
- Колонка причин скрывается на узких экранах, причина видна в панели деталей.
