# Подключение агентов и песочница

## Пять способов подключить агента

| Маршрут в мастере | Кто инициатор | Что вы получаете |
|---|---|---|
| Сервис или сценарий (n8n, Dify, бот) | Агент сам обращается к Finvex | Ключ, адрес `/gateway/v1/propose`, заголовок и пример тела для узла HTTP-запроса |
| Приложение с MCP | Приложение вызывает Finvex как инструмент | Готовый блок конфигурации MCP |
| Мой код | Ваш код | Примеры на Python и curl |
| Агент по адресу | Finvex сам вызывает ваш агент | Вы вводите адрес (и ключ вызова); Finvex отправляет `{symbol, context, instructions, format}` и ждёт JSON с полем `action` |
| Нейросеть | Finvex сам вызывает модель | Роль, тикеры, при желании свои адрес, модель и ключ |

После создания внешнего агента мастер показывает «Ждём первого обращения агента…» и сам сообщает, когда запрос пришёл.
Ответ агента по адресу принимается в разных формах: `{"action": ...}`, `{"output": "..."}`, `[{"json": {...}}]`, текст с JSON внутри.
Любой сбой агента означает «ничего не делать»: заявка в шлюз не уходит.

Finvex слушает только `127.0.0.1`. Агент на другом компьютере достучится до него только через туннель или прокси, а агент по адресу
может быть на `http://localhost:порт` или на публичном `https`-адресе (внутренние сети и перенаправления блокируются).

## Удаление

«Отозвать» оставляет агента и историю. «Удалить» убирает агента, его секреты и все его вердикты из журнала. Цепочка хэшей
пересобирается, в конец добавляется одна контрольная запись («удалено N записей», вершина цепочки до удаления). Содержимое
удалённых записей не сохраняется. Хэши записей после первой удалённой меняются. Действие необратимо.

## Песочница

Отдельный слой с собственным шлюзом в памяти: её вердикты не попадают в рабочий журнал и статистику, заявки не исполняются,
а правила, данные и аналитика берутся рабочие. Источник решения выбирает пользователь:

- модель из «Настроек»;
- другой API модели (свои адрес, модель, ключ; ключ не сохраняется);
- подключённый агент;
- другой API агента по адресу (n8n, Dify, свой сервис);
- аналитик Finvex: прозрачные правила по режиму рынка, ADX и RSI, без модели и ключей.

Кнопка «Проверить правила шлюза» прогоняет шесть типичных намерений (нормальное, огромное, без обоснования, с опечаткой в цене,
короткая продажа, повтор) и показывает реакцию шлюза. Агент и модель для этого не нужны.

## Что не проверено

Тесты используют подставные модели и локальный HTTP-сервер вместо n8n и Dify. Реальные n8n, Dify, Claude Desktop, провайдеры моделей и
внешний вид интерфейса в браузере не проверялись.
