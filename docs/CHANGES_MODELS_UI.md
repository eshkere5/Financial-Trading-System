# Что изменилось

- «Настройки»: выбор провайдера модели из списка вместо ручного адреса; локальные модели (Ollama) работают без ключа.
- Меню подключения источников данных убрано из интерфейса. Источники читаются из `configs/providers.yaml`: шлюзу нужны рыночные
  данные для проверок (свежесть цены, часы торгов, размер позиции). API `/api/adapters` не удалён.
- Ключ DEEPSEEK_API_KEY больше не отправляется провайдерам, кроме DeepSeek.
- «Агенты»: мастер подключения вместо одной кнопки MCP, удаление агентов, время последнего обращения.
- «Песочница»: отдельный слой, выбор источника решения, проверка правил. Подробности в docs/AGENTS.md.
- Набор для LiteLLM: `scripts/start-litellm.ps1`, `deploy/litellm/`, `docs/LITELLM.md` (латиница в скрипте и конфигурации).
